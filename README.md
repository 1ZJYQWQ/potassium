# potassium
极致的 Minecraft 客户端优化模组。通过并行任务队列和内存复用，显著提升高视距、复杂地形下的帧率稳定性，大幅消除瞬间掉帧。
## ⚠️ 状态说明
本项目当前处于早期开发阶段，部分核心算法正在重构中，如有 Bug 欢迎提 Issue。

## 📖 简介
Potassium 基于 Minecraft 公开 API 和通用并发理论独立开发，旨在解决原版在高分辨率高视距下的 CPU 瓶颈和 GC 卡顿。

*测试环境：Minecraft 1.21 / Java 21 /  (Radeon 780M) / 2560x1600 / 32区块渲染距离 / 控制变量法（相同种子、坐标、朝向）*

| 指标 | 原版 | Potassium |
| :--- | :--- | :--- |
| **平均 FPS** | 71 | **77** |
| **GPU 占用率** | 37% | **35%** |
| **CPU 主线程耗时** | 39.8ms | **30.4ms** (↓24%) |
| **区块吞吐量** | 7205 | **8281** |
